# Misc

### **1.** _Bundle Up_ (1.21.1, 1.21.6+)

- Now, simply hover your mouse over the bundle and press the assigned key (unbound by default, R before 10.5.0) to store items with a single click, maximizing your backpack space.

### **2.** _Click Through_ (26.2+)

- Right-click through wall signs, banners and item frames to interact with the container behind them.
- Sneak-click to interact with the sign or item frame itself.
- Can be restricted to only click through when the block behind is a container; extra container block IDs are configurable.
- When holding a dye, ink sac or honeycomb, sneak-click applies the item to the sign while normal clicks pass through.
- Toggle the feature in game with the assigned key (unbound by default, F9 before 10.5.0).
