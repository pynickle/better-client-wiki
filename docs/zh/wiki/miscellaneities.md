# 杂项

### **1.** _一键收纳_ (1.21.1, 1.21.6+)

- 将鼠标悬停在收纳袋上并按下分配的按键（默认未绑定，10.5.0 之前为 R 键），即可自动收纳物品，最大化背包空间。

### **2.** _点击穿透_ (26.2+)

- 右键可穿过墙上的告示牌、旗帜和物品展示框，与它们背后的容器交互。
- 潜行点击则与告示牌或物品展示框本身交互。
- 可限制为仅在背后方块是容器时穿透；额外的容器方块 ID 可配置。
- 手持染料、墨囊或蜜脾时，潜行点击可将物品应用到告示牌上，普通点击则穿透到背后。
- 可使用分配的按键在游戏中切换此功能（默认未绑定，10.5.0 之前为 F9 键）。
