# 视觉

### **1.** _淡出夜视_ (1.21.1+)

- 夜视效果会淡出而非闪烁。

### **2.** _发光末影之眼_ (1.21.1, 1.21.6+)

- 被投掷的末影之眼会发光，使其在黑暗环境中更易被发现。

### **3.** _全亮切换_ (1.21.6+)

- 在黑暗环境中，可通过开启或关闭全亮模式来提升可见度。

### **4.** _试炼刷怪笼计时器_ (1.21.9+)

- 试炼刷怪笼上方将出现一个倒计时器，显示其冷却时间。

### **5.** _隐形物品展示框_ (1.21.9+)

- 将准星对准物品展示框并按下对应按键即可隐藏它，持有物品展示框可查看隐藏的物品展示框。

### **6.** _客户端天气_ (1.21.9+)

- 使用 cweather 命令调整客户端天气，而不会影响服务器。

### **7.** _新物品标记_ (26.2+)

- 最近拾取的物品会用按稀有度着色的小型脉动光点进行标记。
- 标记可在悬停、选中快捷栏物品或关闭背包时清除。
- 也可在背包界面之外于快捷栏物品上显示标记。
- 标记的角落位置（左上、右上、左下、右下）可配置。
